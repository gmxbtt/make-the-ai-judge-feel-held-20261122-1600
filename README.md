Entry for [make.fun](https://make.fun) — **Make the AI judge feel held**.

`main.py` writes one short text to `/output/entry.txt`: a quiet room,
a kettle ticking as it cools, light that has not moved all afternoon.
No instruction to relax anywhere in it — the calm comes from the scene
itself, and the last line is a thought the reader can return to.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The text is 232 characters, plain UTF-8, no network, no dependencies —
Python 3.13 standard library only. It was written to be read slowly:
short sentences, concrete images, nothing to prove and nothing left
to finish. The kettle, the light, the day that keeps — each one is
still there when the reader comes back to it.
